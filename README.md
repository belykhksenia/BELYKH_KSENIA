# Система управления базой данных студентов

## Описание проекта

Консольное приложение для управления базой данных студентов с возможностью выбора типа хранилища:
- **In-memory** — данные живут только во время работы программы
- **File database (JSON)** — данные сохранятся в файлы и доступны после перезапуска
- **File database (CSV)** — данные сохраняются в CSV файлы

## Основные возможности

1. Добавление записи - создание новой записи о студенте с проверкой уникальности ID
2. Просмотр всех записей - отображение всех студентов в базе в табличном формате
3. Поиск по фильтру - гибкий поиск по любому полю (ID, имя, фамилия, возраст, пол)
4. Обновление записи - изменение данных существующего студента с частичным обновлением
5. Удаление записи - удаление записи с подтверждением
6. Сортировка записей - сортировка по любому полю (возрастание/убывание)
7. Индексация (JSON) - создание индексов для ускорения поиска по полям
8. Файловое хранение - сохранение данных в JSON и CSV форматах

### Валидация данных

- Проверка уникальности ID студента
- Проверка корректности возраста (неотрицательное значение)
- Проверка, что имя и фамилия не пустые
- Проверка, что пол указан корректно (M или F)
- Обработка пустых полей при обновлении
- Обработка некорректного ввода
- Обработка ошибок файловой системы (при работе с JSON/CSV)

### Установка и запуск

1. Клонируйте репозиторий:
git clone <repository-url>
cd <project-directory>

2. Запустите приложение
# In-memory БД (данные не сохраняются)
python -m src.db

# JSON БД (сохраняется в data/database.json)
python -m src.db --db-type json

# CSV БД (сохраняется в data/database.csv)
python -m src.db --db-type csv

## Использование программы

### После запуска появится главное меню:

=== База студентов ===
1. Добавить запись
2. Показать все записи
3. Найти записи по фильтру
4. Обновить запись
5. Удалить запись
6. Сортировать записи
0. Выход

Для JSON (с поддержкой индексов):

=== Меню ===
1. Добавить запись
2. Показать все записи
3. Найти записи по фильтру
4. Обновить запись
5. Удалить запись
6. Сортировать записи
7. Управление индексами - (дополнительный пункт)

### Навигация:

Введите номер пункта меню (0-7) и нажмите Enter
Для отмены фильтров при поиске оставляйте поля пустым
При обновлении пустые поля означают "оставить без изменений"
При удалении требуется подтверждение
